## Задание 2. Исследование типов и преобразований

### Отчёт по результатам выполнения выражений

| Выражение | Ожидание до запуска | Фактическое значение | Тип результата | Объяснение |
| :--- | :--- | :--- | :--- | :--- |
| `"8" + 2` | `"82"`, `string` | `"82"` | `string` | **Объединение строки с числом:** Бинарный плюс выполняет конкатенацию (склеивание), если хотя бы один из операндов является строкой. Число `2` автоматически приводится к строке `"2"`. |
| `"8" - 2` | `6`, `number` | `6` | `number` | Оператор вычитания не определён для строк, поэтому он автоматически преобразует строку `"8"` в число `8` перед операцией. |
| `Number("8") + 2` | `10`, `number` | `10` | `number` | Функция `Number("8")` явно преобразует строку в число `8`. Затем выполняется стандартное математическое сложение двух чисел. |
| `"12" > "3"` | `false`, `boolean` | `false` | `boolean` | Обе строки сравниваются посимвольно (по кодам Unicode). Первый символ `"1"` имеет меньший код, чем символ `"3"`, поэтому выражение ложно. |
| `12 === "12"` | `false`, `boolean` | `false` | `boolean` | Оператор строгого равенства `===` сравнивает значения и их типы без автоматического приведения. Число не равно строке. |
| `Number("")` | `0`, `number` | `0` | `number` | **Преобразование пустой строки:** Согласно спецификации JavaScript, явное приведение пустой строки (или строки только из пробелов) к числу всегда возвращает `0`. |
| `Number("text")` | `NaN`, `number` | `NaN` | `number` | **Преобразование NaN:** Строка `"text"` не содержит корректного числового значения. При попытке преобразования JavaScript возвращает специальное значение `NaN` (Not-a-Number), которое относится к числовому типу. |
| `Boolean("false")` | `true`, `boolean` | `true` | `boolean` | **Логическое преобразование непустой строки:** Функция `Boolean` возвращает `false` только для строго определённых "ложных" значений (`0`, `""`, `null`, `undefined`, `NaN`, `false`). Любая непустая строка, даже `"false"`, превращается в `true`. |
| `typeof null` | `"object"`, `string` | `"object"` | `string` | **Разделение значения и типа:** Выражение возвращает текстовое значение `"object"`. Тип самого этого результата — `string`, так как оператор `typeof` всегда возвращает строку. Это историческая особенность языка. |
| `typeof NaN` | `"number"`, `string` | `"number"` | `string` | **Разделение значения и типа:** Выражение возвращает текстовое значение `"number"`. Тип самого этого результата — `string`, поскольку результатом работы `typeof` является строка. |
